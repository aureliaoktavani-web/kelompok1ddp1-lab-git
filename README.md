# contoh/inspirasi:
1. Anda mengangkat masalah terkait Mental Health Disorder tertentu. Anda kemudian mengusulkan sebuah game (dengan library PyGame, https://www.pygame.org/docs/) yang alur ceritanya memberikan experience dan awareness terhadap suatu Mental Health Disorder;
2. Anda melihat bahwa para penjual di Kantin Pacil mengalami masalah terkait pemesanan; dan Anda melihat perlu adanya pemesanan menu secara online agar memaksimalkan banyaknya pembeli. Anda kemudian aplikasi berbasis Web (dengan platform Django, https://www.djangoproject.com/) agar bisa memberikan ruang interaksi antara Penjual dan Pembeli. Tidak hanya itu, aplikasi Web tersebut mempunyai fitur-fitur lain seperti Business Analytics, yang dapat digunakan penjual untuk mempelajari pola-pola pembeli;
3. Anda melihat bahwa mahasiswa Fasilkom cukup kesulitan untuk memantau pengumuman-pengumuman atau informasi dari setiap halaman mata kuliah di SCELE. Anda kemudian mengusulkan sebuah program python berbasis command prompt/console, yang menerima input akun SCELE Anda, dan kemudian melakukan automation ke halaman SCELE dengan menelusuri setiap halaman kuliah yang Anda enroll dan melakukan scraping informasi pengumuman, dan kemudian menampilkan semuanya ke layar di command prompt;
